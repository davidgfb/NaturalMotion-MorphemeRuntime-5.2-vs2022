# NaturalMotion morpheme:runtime 5.2 Distribution

This is a commercial distribution of NaturalMotion's morpheme:runtime, version 5.2.

This distribution contains a plethora of development tools for easy integration of the morpheme Engine into other environments. such tools include the euphoria Engine/toolkit, runtimes, asset compilers, morpheme bundle loader, & the required tools meant for use with morpheme:connect.

The repository seen here is a modified version of the original 5.2 runtime made to be compatible with morpheme:connect 3.6.2.

The untouched distribution can be retrieved from https://github.com/CoolMiddleware/NaturalMotion-MorphemeRuntime-5.2 or from the warz client leak, hosted at https://github.com/bizkut/warz-client/tree/master/External/NaturalMotion

Please keep in mind that any and all modifications made to the morpheme:runtime 5.2 codebase seen here is of pure educational purpose, we encourage users to not, in any way shape or form, use this distribution for commercial purposes.
